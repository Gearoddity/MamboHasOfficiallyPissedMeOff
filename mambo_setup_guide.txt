====================================================================
1. RASPBERRY PI 5 (PRODUCTION SETUP)
====================================================================

1. Update system and install the lightweight MP3 audio player (mpg123):
   sudo apt update
   sudo apt install mpg123 -y

2. Verify Python 3 and Tkinter are installed (usually standard on Raspberry Pi OS):
   sudo apt install python3-tk -y

3. Navigate to the project directory:
   cd /path/to/MamboHasOfficiallyPissedMeOff

4. (Optional) Create and activate a virtual environment:
   python3 -m venv venv
   source venv/bin/activate

5. Install required Python packages (Vosk for local voice recognition, requests, etc.):
   pip install --upgrade pip
   pip install vosk requests
   # Note: No pygame or playsound required anymore!

6. Run the assistant:
   python3 main.py


====================================================================
2. macOS (DEVELOPMENT & TESTING)
====================================================================

1. Ensure Python 3 and Tkinter are installed (via Homebrew if needed):
   brew install python-tk

2. Clone/navigate to the project repository.

3. Set up a virtual environment:
   python3 -m venv venv
   source venv/bin/activate

4. Install dependencies:
   pip install vosk requests

5. Run the assistant:
   python3 main.py
   *(Note: macOS uses the built-in `afplay` utility for audio playback automatically).*


====================================================================
3. WINDOWS (DEVELOPMENT & TESTING)
====================================================================

1. Open PowerShell or Command Prompt in the project folder.

2. Create and activate a virtual environment:
   python -m venv venv
   venv\Scripts\activate

3. Install dependencies:
   pip install vosk requests

4. Run the assistant:
   python main.py
   *(Note: Windows uses built-in .NET PresentationCore MediaPlayer for audio).*
